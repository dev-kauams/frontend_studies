# 🧠 SETOR 01: LOGIC CORE (JavaScript & TS)

### 📌 DIRETRIZES DE USO
**O que entra aqui:**
* Algoritmos e Lógica de Programação.
* Manipulação do DOM (fazer coisas aparecerem/sumirem na tela).
* Consumo de APIs usando `fetch` puro.
* Arquivos `.js` e `.ts`.

**O que NÃO entra aqui:**
* Layouts complexos (o foco aqui é Lógica, não beleza).
* React Components.

---

### 🗺️ MINI-ROADMAP TÁTICO
O objetivo é saber Javascript tão bem que Frameworks pareçam fáceis.

- [ ] **Nível 1: O Básico Bem Feito**
    * Variáveis (`let`, `const`) e Tipos de Dados.
    * Funções e Arrow Functions.
    * Condicionais e Loops (`map`, `filter`, `reduce` - **CRUCIAL**).
- [ ] **Nível 2: DOM & Eventos**
    * `querySelector`, `createElement`, `appendChild`.
    * Event Listeners (`click`, `submit`, `input`).
- [ ] **Nível 3: Assincronicidade (O Terror)**
    * Callbacks vs Promises.
    * Async / Await.
    * Try / Catch block.
- [ ] **Nível 4: TypeScript Intro**
    * Tipagem básica (string, number, boolean).
    * Interfaces e Types.
