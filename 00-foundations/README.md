# 🧱 SETOR 00: FOUNDATIONS (A Base)

### 📌 DIRETRIZES DE USO
**O que entra aqui:**
* Apenas arquivos `.html` e `.css` puros.
* Estudos de Semântica, Acessibilidade (A11y) e SEO.
* Layouts (Flexbox/Grid) sem JavaScript.

**O que NÃO entra aqui:**
* React, Vue ou qualquer Framework.
* Lógica complexa de JavaScript (apenas scripts básicos de UI são tolerados).

---

### 🗺️ MINI-ROADMAP TÁTICO
Siga esta ordem para dominar a renderização:

- [ ] **Nível 1: HTML Semântico**
    * Entender a diferença entre `<div>`, `<section>`, `<article>` e `<main>`.
    * Uso correto de Heading Tags (`h1` a `h6`).
- [ ] **Nível 2: CSS Box Model**
    * Entender `margin`, `border`, `padding`, `content`.
    * Dominar `box-sizing: border-box`.
- [ ] **Nível 3: Layout Moderno**
    * **Flexbox:** Para alinhamentos 1D (linhas ou colunas).
    * **Grid:** Para layouts 2D (áreas complexas).
- [ ] **Nível 4: Responsividade**
    * Media Queries (`@media`).
    * Unidades relativas (`rem`, `em`, `vh`, `vw`, `%`).
