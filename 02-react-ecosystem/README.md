# ⚛️ SETOR 02: REACT ECOSYSTEM

### 📌 DIRETRIZES DE USO
**O que entra aqui:**
* Projetos criados com Vite ou Next.js.
* Estudos de Hooks, Componentes e Estado.
* Testes de bibliotecas (Router, Redux, Zustand).

**Nota:** Cada pasta aqui dentro deve ser um mini-projeto independente (ex: `todo-list`, `weather-widget`).

---

### 🗺️ MINI-ROADMAP TÁTICO
A evolução do Front-end moderno.

- [ ] **Nível 1: Pensando em React**
    * JSX e Componentização.
    * Props vs State.
    * Renderização Condicional.
- [ ] **Nível 2: Hooks Essenciais**
    * `useState` (Memória do componente).
    * `useEffect` (Efeitos colaterais e ciclo de vida).
    * `useRef` (Acessar elementos DOM).
- [ ] **Nível 3: Ecossistema & Estado**
    * React Router (Navegação).
    * Context API ou Zustand (Estado Global).
    * React Hook Form (Formulários performáticos).
- [ ] **Nível 4: Next.js (Server Side)**
    * Estrutura de pastas (App Router).
    * Server Components vs Client Components.
